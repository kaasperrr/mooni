# 🌙 Mooni — курс программирования для детей

Статический сайт + админ-панель для онлайн-школы программирования Mooni.
Готов к загрузке в GitLab и автодеплою на GitLab Pages.

## Как запустить локально

Никакой сборки не требуется — это чистый HTML/CSS/JS.

1. Откройте `index.html` в браузере (он перекинет на `site/index.html`),
   **или** сразу откройте `site/index.html`.
2. Админ-панель: `admin/login.html` → `admin/index.html`.

Для корректной работы относительных путей рекомендуется поднять локальный
сервер (просто открыть файл тоже работает, но `video`/`fetch` иногда лучше
себя ведут через сервер):

```bash
# любой из вариантов
npx serve .
python3 -m http.server 8080
```

## Загрузка на GitLab

```bash
cd mooni-project
git init
git remote add origin <ссылка-на-ваш-репозиторий-gitlab>
git add .
git commit -m "Первая версия сайта Mooni"
git branch -M main
git push -u origin main
```

После пуша в ветку `main` сработает `.gitlab-ci.yml` и GitLab автоматически
опубликует сайт на **GitLab Pages**:

- `https://<namespace>.gitlab.io/<repo>/` — редирект на сайт
- `https://<namespace>.gitlab.io/<repo>/site/` — сайт для учеников
- `https://<namespace>.gitlab.io/<repo>/admin/` — админ-панель

> Включите Pages в настройках репозитория: **Settings → Pages** (в новых
> версиях GitLab Pages включаются автоматически после первого успешного pipeline).

## Что нужно подключить самостоятельно (backend)

Сейчас всё работает как **фронтенд-демо** (без сервера): загрузка видео —
имитация прогресса, тесты и обращения поддержки сохраняются как разметка/
`localStorage`, а не в базу данных. В коде оставлены комментарии
`// TODO: backend` в местах, где нужно подключить реальный API:

- `admin/js/admin.js` — отправка видеофайла на сервер/хранилище (например,
  S3-совместимое хранилище или Cloudflare Stream), сохранение теста в БД,
  отправка ответа поддержки пользователю
- `site/js/support-chat.js` — передача сообщений живому куратору/боту

Рекомендуемый стек для backend (не входит в этот пакет): Node.js/Express
или Django + PostgreSQL, хранение видео — S3/Cloudflare R2 + плеер вроде
Video.js или Mux.
